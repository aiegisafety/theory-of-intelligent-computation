# TIC 实验5 — 带宽定律的首次非玩具检验（v2 重做）

日期：2026-08-02 · 执行：Opus 5 · 代码与数据：`experiment5_v2/`
前置：v1（Gemini 3.6 执行）已判定作废，原因见 §7。

---

## 0. 一句话结论

**带宽定律的形式成立，常数不成立。**

协作崩塌阈值 $C^*$ 由任务熵率 $h_\theta$ 决定，对物理熵率 $h$（+2.000 比特）与物理状态数（×16）几乎完全免疫——这是**双向解离**，不是单向相关。但 $C^*$ 系统性地落在 $h_\theta$ **下方约 0.85 比特**，且崩塌是平滑的而非陡降。**定理3/6 预测的"跟随谁"对了，"在哪崩"没对。**

---

## 1. 为什么必须重做，以及这次的架构区别

v1 的三份数据全部作废，根因是**智能体的决策从未经过信道**：策略表由真实联合状态索引，信道只在 $C<3$ 时注入一点噪声。因此 $C=1$ 比特时成功率已经是 1.000——测的不是带宽。

v2 用**架构**而非**代码审查**排除这一点：

- `choose_action(role, own_x, own_y, off_x, off_y, m)` 的参数里**物理上不存在**对方的真实状态。
- 新增**信道消融对照**（反坑第7条）：把所有传输符号随机化后重跑。若成绩不塌，说明决策没走信道，该批数据作废。
  **实测：最佳成绩 0.950 → 消融后 0.017。** 九个配置的消融值全部 ≤0.033。信道是承重的。

这条消融测试是本次方法上最重要的产出：**它把"是否真的测到了要测的东西"从人工审查变成了一次可自动执行的对照实验。** v1 若跑过它会当场暴露。

## 2. 环境：为什么这次的抽象是"算出来的"

$N\times N$ 环面，两个 agent，任务为**二维会合**：两者须在两个轴上同处一个 zone，$\mathrm{zone}(x,y)=(x \bmod m,\ y \bmod m)$。

关键在于：**没有任何代码告诉精化算法"mod m"这件事。** 算法只拿到一个原始标签数组和一个原始转移核。

### 一次被算法纠正的预测（值得记下来）

我最初预测典范商为 $m^2$ 块（$x_1\bmod m,\ x_2\bmod m$）。**算法返回 $m$ 块，而算法是对的**：标签只依赖 $(x_1-x_2)\bmod m$，而这个差本身动力学封闭，于是**绝对位置整体塌缩**。修正预测后（二维会合）：

$$|S/\!\sim_\theta^*| \;=\; m^2 \quad\text{via}\quad \big((x_1-x_2)\bmod m,\ (y_1-y_2)\bmod m\big)$$

在 1,296 / 5,184 / 20,736 三个状态空间上逐一验证，**全部命中**（`sanity_check.py` CHECK 3）。1296 → 4 块是一次非平凡的塌缩，且是算法自己找到的。

> 这是形式化第二次纠正作者：第一次是定理5 推翻"深思价值命题"，这次是精化算法推翻我的手算预测。

### 两条互相独立的规模轴

| 轴 | 手段 | $|S|$ | $h$ | $h_\theta$ |
|---|---|---|---|---|
| **A 状态数** | 网格 $6\to12$ | ×16 | 不变 | 不变 |
| **B 熵率** | 全局"天气"变量 $K=1\to4$（均匀跳变、agent 不可影响、不进目标） | ×4 | **+2.000 比特** | 不变 |

轴 B 是 v1 缺的那一半。v1 的"10倍规模"只让 $h$ 从 4.37 动到 4.44——因为**随机游走的熵率不随状态数增长**，v1 的规模轴在信息论上几乎是空转。轴 B 用一个任务无关的随机源精确加 $\log_2 4=2$ 比特，同时 $h_\theta$ 在数学上分毫不动。实测：$h$ 4.6439 → 6.6439，$h_\theta$ 1.9027 → 1.9027。

## 3. 主结果：双向解离

编码器两种，**用同一个预测编码器、同一个码字表大小**，唯一区别是编码什么：class 编操作块（速率 $h_\theta$），state 编原始物理态（速率 $h$）。

### A. 固定 $|S|$ 与 $h$，只动 $h_\theta$ → 阈值必须动

| | $|S|$ | $h$ | $h_\theta$ | $C^*$ |
|---|---|---|---|---|
| m=2 | 1296 | 4.644 | 1.903 | **1.20** |
| m=3 | 1296 | 4.644 | 3.099 | **1.96** |

$\Delta h_\theta=+1.196 \Rightarrow \Delta C^*=+0.763$，此时 $h$ 与 $|S|$ **逐位相同**。

### B. 固定 $h_\theta$，动其他一切 → 阈值必须不动

| | 变动 | $C^*$ 变化 |
|---|---|---|
| m=2 | $h$: 4.644 → 6.644（**+2.000 比特**） | +0.05 |
| m=2 | $|S|$: 1,296 → 20,736（**×16**） | +0.05 |
| m=3 | $h$: 4.644 → 6.644（**+2.000 比特**） | **−0.01** |
| m=3 | $|S|$: 1,296 → 20,736（**×16**） | +0.36 |

**加两个比特的物理不确定性，阈值动了 0.05 和 −0.01 比特。**

### C. 总体离散度

$$\mathrm{sd}(C^*-h_\theta)=0.214\ \text{比特}\qquad \mathrm{sd}(C^*-h)=1.076\ \text{比特}$$

阈值跟随 $h_\theta$ 的紧度是跟随 $h$ 的 **5 倍**。

### D. class vs state 编码

$h=4.644$、扫描上限 $C=4.58$。state 编码器在 $m=3$ 与全部 $K=4$ 配置下**从未越过 0.5**（$h>C_{\max}$，符合预期）；class 编码器在 $C\approx2$ 就到顶。$m=2$ 基线配置下 state 编码器的交叉点 $C^*=4.46$，与 $h=4.644$ 相差 0.18 比特——**state 侧的阈值确实落在 $h$ 上，而不是 $h_\theta$ 上。** 这是同一实验内的正对照：两个编码器各自落在自己该落的那条线上。

## 4. 不成立的部分（必须写在这里）

**1. 常数偏低。** $C^*-h_\theta$ 的均值是 **−0.846 比特**，六个点全为负。阈值稳定地落在 $h_\theta$ **下方**。

原因可诊断：判据取"成功率越过 0.5"，而会合任务在**部分信息**下仍能部分完成——agent 不需要无误跟踪操作态就能靠近。所以 $h_\theta$ 是"无误跟踪"的门槛，不是"任务成功一半"的门槛。**理论若要预测 $C^*$ 的位置，需要一条把任务容错度接进来的结果，目前没有。**

**2. 崩塌是平滑的，不是相变。** $m=3$ 的曲线从 0.23 单调爬到 0.82，没有陡降。"崩塌阈值"是我用 0.5 交叉人为定义出来的。**理论此前的叙述隐含了一个尖锐的相变，数据不支持。**

**3. $m=6$ 整档作废（难度受限，非带宽受限）。** $h_\theta=3.539$，但成功率在**所有** $C$ 上都封顶在约 0.10。诊断：$m=6$ 时 zone 即单元格，要求连续 6 步精确同格，噪声 $p=0.15$ 下两 agent 同时留在原地的概率约 $0.85^2=0.72$，六步约 $0.14$——**任务本身几乎不可完成，与带宽无关。** 按反坑第3条剔除，不进阈值统计。

这给出定律的一条边界条件：**带宽定律给出协作的上界，不保证可达性。** 控制问题本身太难时，$C\ge h_\theta$ 不是充分条件。这一点此前没有被写清楚。

**4. 未做的次预测。** 本体漂移版（崩塌点应右移到 $h_\theta+h_A$，即定理11 的非玩具版）**没有跑**。定理11 仍然只有玩具级证据。

## 5. 这批数据能支撑什么、不能支撑什么

**能：** 定理3、定理4（内禀带宽 $h_\theta$ 的可操作性与可发现性）、定理6 的**定性形式**——协作代价由任务抽象而非物理复杂度定价，且这一点在 $|S|$ 变 16 倍、$h$ 加 2 比特下稳定。九个配置里没有一个反例。

**不能：** 任何关于阈值**精确位置**的主张。定理2 的 $H_S\ge h-C$ 与定理6 的连续退化界在本实验中**未被定量检验**，只有方向一致。定理11 的两级速率条件**未被检验**。

**诚实的净收益：** TIC 现在有一个**独占的、经验支撑的定性预测**（协作成本由 $h_\theta$ 定价、对 $h$ 与 $|S|$ 免疫），和一个**被证伪的定量预测**（阈值不在 $h_\theta$ 上）。这比全部通过更有价值，因为它指出了下一条要证的定理。

## 8. 下一步（按价值排序）

1. **补一条"容错阈值"定理**：把任务对跟踪误差的容忍度 $\epsilon$ 接进来，预测 $C^*(\epsilon)$ 而不只是 $C^*\ge h_\theta$。这是本实验直接逼出来的缺口，且有数据可拟合。
2. **跑本体漂移版**（次预测 b）：检验 $C^*$ 是否右移到 $h_\theta+h_A$。定理11 目前是理论里经验支撑最薄的一条。
3. **连续状态版本**：这仍是"表格死"的正面测试，本实验完全没有触及——20,736 个状态仍是表格。
