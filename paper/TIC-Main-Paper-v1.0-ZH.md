日期：2026-08-02

## 摘要

我们提出一个关于**智能计算**的形式理论。核心论点是：

> **智能计算 = 在目标所决定的最粗抽象上选择状态迁移。**

这句话的每一个部分都是可证的、可测的、可证伪的。具体地：

1. **抽象不是设计者选的,是算出来的。** 给定目标与动力学，存在**唯一最粗**的任务充分等价关系 $\sim_\theta^*$，并可在多项式时间内算出（定理4）。设计者没有自由度。

2. **每个任务有一个内禀带宽 $h_\theta$。** 多智能体协作所需的信道容量由 $h_\theta$ 定价，**与物理状态空间的大小和物理熵率无关**（定理6）。我们用三个相互独立的实验检验了这一点：把物理熵率加 2.000 比特、把状态数乘 16、把连续状态的维数从 4 提到 20——阈值分别移动 0.05 比特、0.36 比特、和 0.02（成绩曲线完全不动）。

3. **阈值不是悬崖,是尾概率。** 零误差形式的带宽定律 $C\ge h_\theta$ 在实测中被证伪：阈值系统性地低于 $h_\theta$，且过渡平滑。我们证明错误率受**每步信息变量的上尾概率**控制（定理14），由此得到容错形式
$$C^*(\varepsilon)\;\approx\;h_\theta+\sigma_\theta\,Q^{-1}(\varepsilon),$$
   并引入第二个每任务量——**操作方差熵** $\sigma_\theta^2$。$h_\theta$ 定阈值的位置，$\sigma_\theta$ 定过渡带的宽度。仅用任务结构（不拟合任何参数）预测阈值，平均误差 0.286 比特，较原预测改善 2.95 倍。

4. **本体漂移只在不可吸收时收费。** 常见的直觉"世界变得越快，需要的带宽越多"是错的。我们证明并实测：漂移若是状态空间的一个对称性，典范抽象会把它整个吸收，代价为零（实测 $h_A$ 拉到 1.18 比特/步，阈值只动 0.024 比特）；漂移若改变"哪些区分算数"，则一比特换一比特（实测斜率 1.000，逐位精确）。修正后的两级速率条件为 $C\ge h_\theta+h_A^{\perp}$，且 $h_A^\perp$ 有可计算的判据（定理11′）。

5. **进入连续极限需要容错。** 在连续状态空间中 $h_\theta$ 作为"比特/步"**不存在**（微分熵依赖坐标系、可为负）。其替代是率失真量 $R_\theta(D)$。这意味着定理14 的容错参数不是补丁，而是**理论能进入连续世界的前提**——零误差的带宽定律在连续空间里根本无法陈述。

我们同时报告全部负结果与有效边界：被证伪的定量速率、失效的高斯近似区间、作废的实验档位、以及我们在自己代码中发现的一处数值缺陷及其影响核查。

# 第一部分　基础

## 1. 出发点：智能不是尽可能多地知道世界

### 1.1 一张地图讲的事

伦敦地铁图不是地理图。它抹掉了真实距离、真实方向、真实曲率，只保留"哪站接哪站、在哪里能换乘"。按任何"忠实描述世界"的标准，它都是一张**错**的地图——站与站的距离全是假的。

但对"我该怎么从 A 到 B"这个任务，它比真实地理图**更好用**。而且不是稍微好用，是好用得多：真实地理图上你要花力气把无关的曲折过滤掉，地铁图已经替你滤完了。

这里有一件值得认真对待的事：

> **那些被抹掉的区分,不是无害的冗余。它们是要付费的。**

付什么费？如果你要把自己的位置实时告诉朋友，用地铁图你说"中央线，往东，下一站牛津广场"；用地理图你得报经纬度。**同一个任务，后者每秒要多传很多比特。** 这笔费用在单机系统里表现为存储和计算，在多智能体系统里直接表现为**通信账单**。

本文的全部内容，是把这个直觉变成可证、可测、可证伪的东西。

### 1.2 一句话主张

$$\boxed{\textbf{智能计算 = 在目标所决定的最粗抽象上选择状态迁移。}}$$

三个词都是承重的：

- **目标所决定**——不是设计者选的。我们会证明抽象是**算出来的**，给定目标与动力学后唯一确定（定理4）。
- **最粗**——不是"尽可能精确地描述世界"。多余的区分按比特/步收费（定理2、6、14）。
- **选择状态迁移**——目的在这里。**不在降熵**：我们会证明把熵当目标是错的（§5.4）。

于是本文标题里那句更通俗的话是：

> **智能不是尽可能多地知道世界，而是尽可能少地需要知道世界，同时仍然能做对事。**

### 1.3 本文的四个结果与它们的关系

```
        定理4  典范抽象  ~θ*  ← 抽象是算出来的，唯一最粗
             │
             │  诱导
             ▼
        内禀带宽 h_θ  ← 每个任务的固有速率
             │
             ├────────────► 定理6  带宽定律  C ≥ h_θ
             │                （被实测修正 ↓）
             ▼
        定理14  容错阈值  C*(ε) ≈ h_θ + σ_θ Q⁻¹(ε)
             │           ← 引入第二个量 σ_θ（操作方差熵）
             ├────────────► 定理11′ 时间维度：C ≥ h_θ + h_A^⊥
             │
             └────────────► 连续极限：h_θ ⇝ R_θ(D)
                             ← 容错是前提，不是补丁
```

**读法**：定理4 造出对象，$h_\theta$ 给它一个数，定理6 说这个数是协作的价格，定理14 说这个价格要按可靠性要求打折，定理11′ 把它推广到时间上，连续极限说明为什么定理14 是必须的。

## 2. 本体：五个原语

### 2.1 为什么要先定原语

一个理论最容易死的方式，是概念无限增殖：每遇到一个现象就加一个新概念，最后什么都能解释、什么都预测不了。我们因此先立一条规矩，并在全文遵守：

> **规则（概念准入）。** 任何概念要进入理论，必须或者是五个原语之一，或者由原语**构造性地定义**，或者出现在某条定理的陈述中。三者都不满足的，是**候选**，不是理论的一部分。

这条规矩在本研究中真的起过作用：它挡下了"涌现的集体状态""状态流形的曲率"等一批看起来漂亮但没有任何定理需要的东西。

### 2.2 五个原语

| 原语 | 记号 | 一句话 |
|---|---|---|
| **状态** | $S$ | 世界此刻的完整刻画 |
| **迁移** | $\tau$ | 状态到状态分布的映射（随机核） |
| **观察** | $O$ | 从状态到证据的映射（一般是多对一的） |
| **深思** | $D$ | 在若干候选迁移中作出承诺的过程 |
| **熵** | $H$ | 不确定性的度量（分两层，见 §3） |

**被明确排除在原语之外的**（它们都是构造出来的，不是基本的）：动作、记忆、身份、目标、约束、语言、共享状态。

举两个说明为什么：

- **动作不是原语。** 一个动作就是"由某个实体承诺的迁移"。把它当原语会导致同一件事有两套记号，且无法自然地表达"环境自己发生的变化"。
- **记忆不是原语。** 我们会证明（定理9）最小任务充分记忆**恰好等于**当前的操作状态。既然能证出来，就不该当假设。

### 2.3 实体是一个索引，不是一个对象

这是一个容易被绕进去的地方，值得单独说。

**问题：** 如果先定义"实体"，再用实体定义"同一性"，那"什么算同一个实体"就得先回答；可回答它又要用到同一性。循环。

**解法：** 不把实体当对象，把它当**索引**。状态写成 $S(E,t)$，状态空间是**纤维化**在一个实体索引集上的。

> **例子。** 就像"第 3 排第 5 座"不是一个人，而是一个位置；谁坐在那里是另一个问题。理论描述座位表的结构，不描述谁坐哪儿。

这样"同一性"就可以在不预设实体本质的情况下被定义为**在时间上保持不变的慢变量**（§12），循环被打开。

## 3. 两层熵

### 3.1 为什么需要两层

**(a) 直觉。** "不确定"有两种很不一样的意思：

- **我不知道是这三种情况里的哪一种**（但我说不出谁更可能）；
- **我认为有 70% 是第一种**。

前者不需要概率，后者需要。绝大多数形式理论（POMDP、Active Inference）直接从后者开始——它们假设智能体有一个概率信念。但这是一个很强的假设。

**(b) 例子。** 急诊分诊。护士看到病人，第一判断常常是："这可能是心梗、可能是胃食管反流、可能是焦虑发作。"她**没有**给出概率，也不需要。她要做的下一件事（做心电图）只依赖于"心梗还没被排除"这个**可能性**事实。

只有当资源要被分配时（"只有一台机器，先给谁用"），概率才变得必要。

**(c) 形式定义。**

> **定义 3.1（Layer 0，可能性层）。** 证据 $e$ 诱导一个**可能性集** $\Omega(e)\subseteq\mathcal S$——所有与 $e$ 相容的状态。其熵为 Hartley 熵
> $$H_0(e)=\log_2|\Omega(e)|.$$
> 这是理论的**定义层默认**：不需要先验。

> **定义 3.2（Layer 1，概率层）。** 若额外给定状态上的概率测度，用 Shannon 熵
> $$H_1(e)=H(S\mid e).$$
> 本文绝大多数定理的**证明**在这一层。

**(d) 为什么非这么定义不可。**

这不是"两种口味任选"。它解决了一个真实的内部矛盾：本理论早期版本在定义处用了 Layer 0（无先验），却在定理证明里用了 Layer 1（有先验）。这是同一份文稿里两个不相容的熵。两层结构把它们分开并各自标注，同时**说清了 TIC 与 POMDP 的分界**：

> TIC 的**定义**不预设先验（Layer 0），这是它与 POMDP 信念状态的区别；TIC 的**定量结果**大多在 Layer 1，这是它能与信息论对接的原因。

**一个重要的经验事实**：在多数实际情形下 Layer 0 的熵是 **0**——证据通常足以把状态钉死在一个可能性上。真正的不确定性往往不在"世界是什么状态"，而在"我该做哪个迁移"。这直接引出下一节。

### 3.2 三种熵，各守一处

| 记号 | 名称 | 问的问题 |
|---|---|---|
| $H_S$ | **状态熵** | 世界现在处于哪个状态？ |
| $H_D$ | **深思熵** | 我将要选哪个迁移？ |
| $H_T$ | **迁移熵** | 选定这个迁移后，会到哪个状态？ |

$H_D$ 是本理论最不常规的一个：**它定义在迁移空间上，不在状态空间上。** 大多数理论只有 $H_S$ 和 $H_T$。

> **例子。** 你站在岔路口。你完全知道自己在哪（$H_S=0$）、也完全知道往左走会到哪、往右走会到哪（$H_T=0$）。但你还没决定走哪条——**这个不确定性是真实的，而且是唯一还剩下的**。它就是 $H_D$。
>
> 传统框架会说"你的策略是随机的"，把它记在策略上。我们认为它值得一个自己的名字，因为**深思的全部工作就是消灭它**。

### 3.3 约束塌缩：不看世界也能降低不确定性

**(a) 直觉。** 约束（"不能闯红灯""预算不超过一万"）不告诉你世界是什么样，但它们**删掉候选迁移**，因此降低 $H_D$。这是一种**不需要新观察**的降熵。

**(b) 例子。** 分诊护士得知"该病人对青霉素过敏"。这条信息没有告诉她病人得了什么病（$H_S$ 不变），但一大批治疗方案当场出局（$H_D$ 下降）。

**(c) 形式结果。**

> **定理1（约束塌缩）。** 若一条约束以概率 $p$ 排除候选迁移（在 Layer 0 的均匀计数意义下），则
> $$\Delta H_0=\log_2\frac{1}{1-p}.$$
> 级联的多条约束其熵减**可加**。

**(d) 为什么值得写下来。** 规划领域早就在做剪枝，但没有人给剪枝**记熵账**。一旦记了账，剪枝就和通信、和带宽在同一个单位下可比了——这是后面所有结果的前提。

## 4. 任务等价与典范抽象

这是全文的技术核心。

### 4.1 什么叫"对这个任务来说是一回事"

**(a) 直觉。** 两个状态在什么条件下可以被当成同一个？回到地铁：对"怎么换乘"这个任务，"车厢里有 40 人"和"车厢里有 41 人"是一回事。但对"还能不能挤上去"这个任务，它们可能不是。

**同一个世界，不同任务，不同的"一回事"。**

**(b) 例子（贯穿全文）。** 你和朋友要在一个环形商场里会合。商场有 360 个位置编号。

- 如果目标是"在同一家店碰面"，那么位置 12 和位置 13（同一家店内）是**一回事**。
- 如果目标是"在同一层碰面"，那么位置 12 和位置 120（同一层）是**一回事**。
- 目标越粗，"一回事"的范围越大，你要传的信息越少。

**(c) 形式定义。**

> **定义 4.1（任务等价）。** 设有限状态集 $\mathcal S$、动作集 $\mathcal A$（每个动作 $a$ 有随机核 $P_a$）、以及目标标注 $g:\mathcal S\to L$。等价关系 $\sim$ 称为 **$\theta$-充分**，若
>
> - **(G) 目标相容**：$S_1\sim S_2\ \Rightarrow\ g(S_1)=g(S_2)$；
> - **(D) 动力学相容**：$S_1\sim S_2\ \Rightarrow$ **对每个动作 $a$** 和每个 $\sim$-块 $B$，
> $$P_a(B\mid S_1)=P_a(B\mid S_2).$$

**(d) 为什么非这么定义不可——两个关键点。**

**第一，(D) 里的"对每个动作"是承重的，不是形式上的讲究。** 我们在连续实验中亲身踩了这个坑：把 (D) 换成"对随机策略平均"之后，抽象把 $+e$ 和 $-e$（"对方在我左边"和"对方在我右边"）合并了——因为目标"距离够近"对左右**对称**。合并在预测目标上完全正确，但**控制器必须区分它们**，它们要求相反的移动。实测：动作平均版本的读出误差 0.194（约等于瞎猜），逐动作版本 0.0055。

> **教训（值得单独记住）：目标预测充分 ≠ 控制充分。** 差别正是那个逐动作量词。后继表示（successor representation）文献常用动作平均版本，在对称任务上会遇到同一个问题。

**第二，为什么用"块转移分布逐步相等"而不是"可达集相等"。** 后者是更弱、更直观的条件，也是本研究早期版本用过的条件——**它是错的**。

> **反例（4 状态，已机器验证）。** 状态 $\{s_1,s_2,a,b\}$，迁移 $s_1\to a$、$s_1\to b$、$s_2\to a$、$a\to b$。
>
> | | 前向可达集 | 后向可达集 | 一步后继 |
> |---|---|---|---|
> | $s_1$ | $\{a,b\}$ | $\varnothing$ | $a,b$ |
> | $s_2$ | $\{a,b\}$ | $\varnothing$ | $a$ |
>
> 可达集完全相同，但从 $s_1$ 一步可达 $b$，从 $s_2$ 不能。**按可达集合并会凭空造出一条 $s_2\to b$ 的迁移，改变系统行为。**

这正是并发理论里花了很多年才厘清的 **trace 等价 vs bisimulation** 之别。定义 4.1 的 (D) 就是 bisimulation 条件。

### 4.2 定理4：最粗抽象存在、唯一、可算

**引理 4.1（并封闭）。** 若 $\sim_1,\sim_2$ 都是 $\theta$-充分的，则它们的并（的传递闭包）$\sim$ 也是。

**证明。** 设 $S,T$ 落在并的同一块中，则存在链 $S=X_0\sim_{i_1}X_1\sim_{i_2}\cdots\sim_{i_k}X_k=T$，每步 $i_j\in\{1,2\}$。

*(G)*：每步保持 $g$，故 $g(S)=g(T)$。

*(D)*：设 $B$ 是并的一个块。由于 $\sim_1$ 细化并，$B$ 是若干 $\sim_1$-块 $C_1,\dots,C_r$ 的不交并。对链中一步 $X\sim_1 Y$：
$$P_a(B\mid X)=\sum_j P_a(C_j\mid X)=\sum_j P_a(C_j\mid Y)=P_a(B\mid Y),$$
中间一步用了 $\sim_1$ 的 (D)。对 $\sim_2$ 同理。沿链传递即得 $P_a(B\mid S)=P_a(B\mid T)$。$\blacksquare$

> **要紧的是中间那个等号**：粗化只是把块概率**相加**，而等式在求和下保持。这正是"充分性向上稳定"的原因——合并不会破坏它。

**定理4（典范抽象）。**

> $\theta$-充分等价关系的族 $\mathcal Q_\theta$ 有**唯一极大元** $\sim_\theta^*$——最粗的 $\theta$-充分等价关系。它由从目标划分出发的**划分精化**得到，多项式时间可算。

**证明。** $\mathcal Q_\theta$ 非空（恒等关系充分），且对并封闭（引理 4.1）；在有限集上这使它成为完全并半格，其极大元即全体成员之并。偏序中的极大元唯一，记为 $\sim_\theta^*$。

*计算。* 令 $\Pi_0$ 为 $g$ 划分，$\Pi_{n+1}$ 按签名
$$s\mapsto\big(P_a(B\mid s)\big)_{a\in\mathcal A,\;B\in\Pi_n}$$
细分 $\Pi_n$ 的每一块。两条：

1. *不动点是充分的*：细化只切不并，故 (G) 保持；平稳意味着同块内任意两态的块转移向量相同，即 (D)。
2. *$\sim_\theta^*$ 细化每个 $\Pi_n$*：归纳。由 (G) 它细化 $\Pi_0$；若它细化 $\Pi_n$，则每个 $\Pi_n$-块是若干 $\sim_\theta^*$-块之并，由 (D) 任意两个 $\sim_\theta^*$-等价的状态有相同的 $\Pi_n$-签名，不会被切开，故它细化 $\Pi_{n+1}$。

由 2，不动点比 $\sim_\theta^*$ 粗或相等；由 1 它充分，而 $\sim_\theta^*$ 是最粗的充分关系，故相等。每轮或严格细化或停止，至多 $|\mathcal S|$ 轮；Paige–Tarjan 式实现为 $O(|\mathcal A|\,|\mathcal S|\log|\mathcal S|)$。$\blacksquare$

### 4.3 定理4 的三个后果

1. **设计者的自由度没有了。** 不能挑一个方便的抽象把后面的带宽定律说成任何样子：给定目标与动力学，$\sim_\theta^*$ 是被逼出来的。
2. **越粗的目标买越小的状态空间。** 若 $g'$ 是 $g$ 的粗化，则 $\sim_{\theta'}^*$ 比 $\sim_\theta^*$ 粗（显然：$\Pi_0'$ 更粗且精化是单调的）。**对世界要求得越少，要知道的就越少。**
3. **TIC 继承了一个算法，不只是一条定理。** bisimulation 最小化/模型最小化是成熟工具（Kanellakis–Smolka；Larsen–Skou；Givan–Dean–Greig）。**这一点必须明说：定理4 的计算内容不是我们的发明，我们的贡献是把它接到带宽上（§6）。**

### 4.4 内禀带宽 $h_\theta$

**(a) 直觉。** 把状态换成它所属的块，得到一条**商链**。这条链每步产生多少新的不确定性，就是这个任务固有的信息速率。

**(b) 例子。** 你要向朋友实时播报你在地铁网中的位置。若任务只是"你到哪一站了"，每步需要的比特由**线网的分叉结构**决定——和车厢里有多少乘客、每人在想什么完全无关，尽管后者的信息量大得多。

**(c) 定义与结果。**

> **定义 4.2（内禀任务带宽）。** $h_\theta$ 为商链（以 $\sim_\theta^*$ 的块为状态）在平稳分布下的熵率。

> **推论 4.2。** $h_\theta\le h$，其中 $h$ 是物理链的熵率。

**(d) 为什么这个量重要。** 因为它把"这个任务有多难"变成了**一个有单位的数**（比特/步）。绝大多数 AI 理论一个数字都不预测。$h_\theta$ 可测、可比、可写进工程预算。本文后面全部的定量结果都挂在它上面。

### 4.5 一次形式化纠正作者的记录

我们认为值得如实记下：在设计验证环境时，作者预测某个会合任务的商为 $m^2$ 块。**算法返回 $m$ 块，而算法是对的**——目标只依赖 $(x_1-x_2)\bmod m$，而这个差本身动力学封闭，于是**绝对位置整体塌缩**。

这类事件在本研究中发生过多次（另见 §5.4、§13.2）。我们把它作为形式化"活着"的证据：**一个只会附和作者的形式系统没有用处。**

# 第二部分　带宽定律

## 5. 熵不是目标

### 5.1 一个很诱人、但是错的口号

本理论的早期版本有一条中心命题，大意是：深思的价值在于它降低未来的状态熵，即
$$\Delta H_D\;\longrightarrow\;\Delta H_S^{\text{future}}.$$
读起来很像那么回事：想清楚 = 更少的意外。当时它被称为"本理论最锐利的陈述"。

**它是假的。** 而且失效有一个精确的刻画。

### 5.2 反例：救援机器人

**(b) 例子。** 一个救援机器人站在两条走廊前。

- **走廊 A**：结构复杂、通向未知区域。走进去之后，你对世界的了解会**变得更不确定**——熵上升。但幸存者在这个方向的可能性高。
- **走廊 B**：一条笔直的死胡同。走进去之后，你对世界的了解**完全确定**——熵下降到零。里面没有人。

按"降熵即价值"，机器人应当选 B。**任何人都知道该选 A。**

### 5.3 定理5 与它的阈值

> **定理5（熵不是目标）。** 存在任务，使得熵减最大的迁移严格劣于最优迁移。失效的充要条件可写成一个阈值：记 $q_{\max},q_{\min}$ 为两条候选路径在目标达成上的成功概率的上下界，则当
> $$q_{\max}+q_{\min}\ \ge\ 1$$
> 时，熵判据与价值判据可以相反。

（构造与数值验证见附录 A.2。）

**这条定理的作用是切断一个混淆：** "熵"一直在替三个不同的问题干活。

| 问题 | 回答 |
|---|---|
| 计算的**对象**是什么？ | 状态的演化 |
| 计算**为了什么**？ | 在目标与约束下选出高质量的迁移 |
| 计算**由什么构成**？ | 维持任务所需的区分，抹掉其余（§1.2） |

旧口号把第二和第三搅在了一起——**它把工作的度量当成了工作的目的。**

### 5.4 取而代之的东西

深思的停机准则不该是"熵降够了"，而是标准的**计算价值**判据（Russell–Wefald）：
$$V(D)=\Delta\,\mathbb E[Q(\tau)]-\lambda\cdot\mathrm{Cost}(D),$$
即"多想一步能让所选迁移的期望质量提升多少，减去想这一步的代价"。**这一条我们直接采用既有工作，不宣称新颖。**

> **记录。** 定理5 是本形式系统第一次推翻作者想要的结论。我们保留这段历史而不是悄悄改写，因为一个理论的可信度部分来自它**否决过自己**的次数。

## 6. 带宽定律

### 6.1 直觉：为什么会有一条速率下界

**(a) 直觉。** 世界每一步都在产生新的不确定性。你的信道每一步只能送 $C$ 比特。如果世界产生得比你送得快，你的落后会**累积**，而且无论你多聪明都追不上——这是记账，不是技巧问题。

**(b) 例子。** 你在给朋友直播你在商场里的位置，一秒一条短信。如果你一秒钟能移动的范围需要 3 比特才能说清，而短信一秒只能传 2 比特，那么**平均每秒你欠他 1 比特**，误差只会越滚越大。攒多久都没用——这不是延迟问题，是速率问题。

### 6.2 定理2 与定理6

> **定理2（残余不确定性下界）。** 在容量 $C$ 比特/步的信道下，接收方对状态的条件熵满足
> $$H_S\ \ge\ h-C.$$
> Layer 0 的对应形式为 $\mathbb E|\Omega(e_{t+1})|\ \ge\ b/2^{C}$。

> **定理6（带宽定律，一般形式）。** 上述下界在放弃可块化假设后仍成立，退化是**连续**的：若抽象只是 $\varepsilon$-充分，则由 Fannes–Audenaert 型不等式，误差以 $\varepsilon$ 的连续函数为界；且由全变差耦合可得故障率的上界。

**关键的一步在于把 $h$ 换成 $h_\theta$：**

> **推论 6.1（操作带宽定律）。** 若各方只需就**任务等价类**达成一致（而非物理状态），则相关的速率是 $h_\theta$ 而非 $h$：
> $$C\ \ge\ h_\theta.$$

**(d) 为什么这一步是新的。** 状态抽象文献（Givan–Dean–Greig、Ferns 等）不谈信道；网络化控制/速率受限估计文献（Tatikonda–Mitter 等）不谈任务抽象。**把两者接起来，得到"每个任务有一个内禀带宽、且协作对物理不确定性免疫"——这一步我们未见先例，它是本文最像原创的部分。**

### 6.3 一个立刻可用的工程推论

> **编码规则：编码类，不要编码状态。**

两个智能体之间应当传输 $[S]_\theta$（任务等价类），而不是原始物理状态。这条规则的收益随物理状态数增大而增大，且**收益体现在通信账单上，不体现在错误率上**——只要带宽够，两种编码的错误率可以一样，差别全在花了多少比特。

## 7. 协作：一致性不等于接地

### 7.1 一个必须分开的混淆

**(b) 例子。** 你和朋友约"在东门见"。

- **情形一**：你俩对"东门在哪"的理解一致，且都正确。→ 见到了。
- **情形二**：你俩都记错了，都以为西北角那个门叫东门。→ **还是见到了。**
- **情形三**：一个人对、一个人错。→ 见不到。

情形二说明一件事：**协作只需要一致，不需要正确。** 而且情形二在很多系统里是**最便宜的稳定态**——统一一个错误比让所有人各自正确要省得多。

### 7.2 两个条件，必须分别命名

> **定义 7.1（一致性 Coherence）。** 两个实体对同一状态归入**相同的任务等价类**。

> **定义 7.2（接地 Grounding）。** 实体所归的类与**客观状态**所属的类相符。

> **定理3（类一致即无可行性冲突）。** 若参与各方一致（定义 7.1），则不存在可行性冲突——各自基于自己的类作出的承诺互相相容。

**(d) 为什么必须拆开。** 因为定理3 的条件**可以被"共同的无知"满足**：两个实体都错、但错得一样，照样满足一致性。这与"理论应当描述有效的智能"直接冲突。拆开之后：

- **一致性**是定理3 真正保证的东西（协调不失败）；
- **接地**是另一个、独立需要的条件（结果正确）。

> **推论（可测、可怕）：协调地共同犯错，是最便宜的稳定配置。**
>
> 这在多智能体系统与人类组织里都能找到对应物，并且它给出一个可检验的预测：在带宽受限的系统中，**一致性会先于接地被优化出来**。

### 7.3 一个实验中真的撞上的例子

在早期仿真中，我们一度观察到两个智能体的"一致率 100%"。查下来是两者用了同一套随机顺序——它们不是在协作，是在**同步地犯同一个错误**。

这既是一个 bug（已修正，见附录 B），也是定理3 的现实演示：**代码相同的两个智能体不是两个智能体。**

## 8. 实验证据一：双向解离

### 8.1 检验什么

带宽定律的核心断言是：**阈值跟随 $h_\theta$，不跟随 $h$，也不跟随状态数。** 单看"阈值和 $h_\theta$ 相关"是不够的——相关可能是巧合。要做的是**双向解离**：

- 固定 $h_\theta$，把别的都改动 → 阈值**必须不动**；
- 固定别的，只改 $h_\theta$ → 阈值**必须动**。

### 8.2 环境设计（以及为什么这样设计）

$N\times N$ 环面上两个智能体，任务为**二维会合**：两者须在两个轴上同处一个区，区 $=(x\bmod m,\ y\bmod m)$。

- **粒度轴 $m$** 改变 $h_\theta$。环面是循环群且移动为 $\pm1$，故当 $m\mid N$ 时 $x\bmod m$ **动力学封闭**——存在非平凡商，且**精化算法自己会找到它**（代码中没有任何地方提到 "mod m"）。
- **规模轴 A**：网格 $6\to12$，状态数 $\times16$，$h$ 几乎不变。
- **规模轴 B**：加一个全局"天气"变量 $K$，均匀随机跳变、智能体无法影响、不进目标标注。它把 $h$ **精确地**抬高 $\log_2K$ 比特，而 $h_\theta$ 在数学上分毫不动。

> **为什么需要轴 B？** 因为**随机游走的熵率不随状态数增长**——它由移动噪声决定。早期一次实验用"状态数 ×3.16"作规模轴，结果 $h$ 只从 4.37 动到 4.44，等于空转。轴 B 是唯一能把 $h$ 真正拉开的办法。

实测：$h$ 从 4.6439 → 6.6439（**恰好 +2.000 比特**），$h_\theta$ 从 1.9027 → **1.9027**（逐位不变）。

### 8.3 结果

**固定 $|S|$ 与 $h$（逐位相同），只动 $h_\theta$：**

| | $\|S\|$ | $h$ | $h_\theta$ | $C^*$ |
|---|---|---|---|---|
| $m=2$ | 1296 | 4.644 | 1.903 | **1.20** |
| $m=3$ | 1296 | 4.644 | 3.099 | **1.96** |

$\Delta h_\theta=+1.196\ \Rightarrow\ \Delta C^*=+0.763$。**该动的动了。**

**固定 $h_\theta$（逐位相同），动其他一切：**

| | 变动 | $\Delta C^*$ |
|---|---|---|
| $m=2$ | $h$：+2.000 比特 | **+0.05** |
| $m=2$ | $\|S\|$：$\times16$ | **+0.05** |
| $m=3$ | $h$：+2.000 比特 | **−0.01** |
| $m=3$ | $\|S\|$：$\times16$ | **+0.36** |

**给物理世界加两个比特的不确定性，阈值动了 0.05 和 −0.01 比特。**

**总体离散度：**
$$\mathrm{sd}(C^*-h_\theta)=0.214\ \text{比特}\qquad \mathrm{sd}(C^*-h)=1.076\ \text{比特}$$
阈值跟随 $h_\theta$ 的紧度是跟随 $h$ 的 **5 倍**。

### 8.4 一个同实验内的正对照

同一批实验里还有一个编码器直接量化**原始物理状态**。它的阈值应当落在 $h$ 上，而不是 $h_\theta$ 上。实测：$C^*=4.46$，而 $h=4.644$，相差 0.18 比特。

> **两个编码器各自落在各自该落的那条线上。** 这比单看一条曲线有说服力得多——它排除了"所有曲线都长这样"的平凡解释。

### 8.5 方法：一条必须做的对照实验

我们建议把下面这条作为此类实验的**标准动作**：

> **信道消融对照。** 把所有传输的符号随机化后重跑。**若成绩不塌，说明决策没有真的经过信道，该批数据作废。**

这条不是多余的谨慎。在本研究的一个早期实现中，智能体的策略表是按**真实联合状态**索引的，信道只起装饰作用——结果是 $C=1$ 比特时协作成功率已经是 1.000，看起来像"理论大获全胜"，实际上什么都没测到。

本文报告的实验中，消融对照的结果是：最佳成绩 **0.950 → 消融后 0.017**，九个配置的消融值全部 $\le0.033$。**信道是承重的。**

> 这条对照把"我们到底测到没测到要测的东西"从人工代码审查变成了一次**可自动执行的实验**。我们认为它比本节的任何一个数字都更值得被别人拿去用。

# 第三部分　容错带宽阈值

## 9. 被证伪的常数

### 9.1 数据说了什么

§8 的实验在确认双向解离的同时，**否掉了带宽定律的两个附带断言**：

**(i) 阈值不在 $h_\theta$ 上。** $C^*-h_\theta$ 的六个测点**全部为负**，均值 $-0.846$ 比特。

**(ii) 崩塌不是相变。** $m=3$ 的成功率曲线从 0.23 单调爬到 0.82，**没有陡降**。所谓"崩塌阈值"是我们用 0.5 交叉人为定义出来的。

理论此前的叙述隐含了 $C=h_\theta$ 处有一道悬崖。**数据说没有。**

### 9.2 这不是一个可以调常数修好的问题

一个诱惑是把定律改成 $C\ge h_\theta-0.85$。这是错的做法——0.85 从哪来？换个任务还是 0.85 吗？

真正的问题是**建模层次错了**：

> $h_\theta$ 是**无误跟踪**所需的速率。而任何真实任务都容忍一定的跟踪错误。旧陈述把 $\varepsilon\to0$ 的极限当成了一般情形。

**(b) 例子。** 你开车用导航。导航需要知道你在哪条**路**上，不需要知道你在哪条**车道**、更不需要知道你在这条车道的哪一厘米。**要求零误差地跟踪你的位置，需要无限的比特。** 实际上你容忍相当大的误差，所以你需要的带宽小得多。

**容错度不是一个可以省略的细节，它是决定价格的那个变量。**

### 9.3 一个必须先想清楚的问题：智能体是怎么编码的

在给出定理之前要固定一个设定，因为它决定了结论的形状。

**智能体每一步都要动作，因此每一步都要译码。** 它不能像通信工程里那样攒够一千个符号再一起解——攒到第一千步的时候，前面九百九十九步的动作早就该做完了。

我们因此考虑**每步预测码**：

> 编码器与译码器共享动力学模型与**上一步的译码值** $v_{t-1}$；码本 $L_M(v_{t-1})$ 取 $P(\cdot\mid v_{t-1})$ 概率最大的 $M=2^C$ 个后继。真值在码本内则精确译出，否则译错，且错误沿 $v$ **传播**（下一步的码本从错的值出发建）。

**(b) 例子。** 你和朋友约定："我每分钟发一条消息，从 1 到 8 编号，代表我最可能去的 8 个地方。"这 8 个地方是根据**你上一分钟在哪**推出来的——所以你不需要每次都从整个商场里选，只需要从"从上个位置一分钟内能到的地方"里选。这就是预测码：**利用相邻时刻的相关性，把每步要传的东西压到远小于"地点总数"。**

这也解释了为什么带宽定律里出现的是**熵率** $h_\theta$（每步的新增不确定性），而不是 $\log_2(\text{类的个数})$。

## 10. 定理14

### 10.1 每步信息变量

> **定义 10.1。** 操作链的**每步信息变量**为
> $$T\;:=\;-\log_2 P(S_{\theta,t+1}\mid S_{\theta,t}),\qquad \mathbb E[T]=h_\theta.$$

**(a) 直觉。** $T$ 是"这一步的意外程度"，以比特计。它的**平均值**就是 $h_\theta$。但它是一个**随机变量**——有些步很好猜（$T$ 小），有些步很意外（$T$ 大）。

**(b) 例子。** 你在地铁上向朋友播报位置。大部分时候下一站是唯一的，$T\approx0$（几乎不用发消息）。到了换乘大站，下一步有五种可能，$T$ 一下子跳到 2 点几比特。**平均是 $h_\theta$，但你需要的是能扛住那些尖峰的带宽。**

### 10.2 引理 14.1（列表覆盖）

> **引理 14.1。** 对任意 $b$ 与任意 $M\ge2^{C}$：
> $$\{x:\ P(x\mid b)\ge2^{-C}\}\ \subseteq\ L_M(b).$$

**证明。** 记 $B=\{x:P(x\mid b)\ge2^{-C}\}$。设存在 $x\in B\setminus L_M(b)$。因 $L_M(b)$ 取的是概率最大的 $M$ 个，其每个元素的概率都 $\ge P(x\mid b)\ge2^{-C}$。于是 $L_M(b)\cup\{x\}$ 有 $M+1$ 个元素、每个概率 $\ge2^{-C}$，总质量
$$\ge(M+1)2^{-C}>2^{C}\cdot2^{-C}=1,$$
与概率归一矛盾。$\blacksquare$

**(a) 直觉。** 概率不小于 $2^{-C}$ 的候选**至多只有 $2^C$ 个**（否则总和超过 1）。所以一个能装 $2^C$ 个的码本，一定装得下所有"够可能"的候选。

### 10.3 定理14

> **定理14。**
>
> **(a) 精确形式。** 一步最优码的错误率为
> $$\varepsilon_{\mathrm{opt}}(C)=1-\mathbb E_{b\sim\mu}\Big[\sum_{x\in L_{2^C}(b)}P(x\mid b)\Big],$$
> 且 top-$M$ 码在所有 $M$ 符号一步码中**最优**。
>
> **(b) 信息谱界。**
> $$\varepsilon_{\mathrm{opt}}(C)\ \le\ \Pr[\,T>C\,].$$

**证明。** (a) 一步译码可覆盖的集合大小上限为 $M$；覆盖质量在取概率最大的 $M$ 个时最大化，故 top-$M$ 最优，错误率即未覆盖的质量。

(b) 由引理 14.1（取 $M=2^C$），$S_{\theta,t+1}\notin L_M(S_{\theta,t})$ 蕴含 $P(S_{\theta,t+1}\mid S_{\theta,t})<2^{-C}$，即 $T>C$。故错误事件含于 $\{T>C\}$，取概率即得。$\blacksquare$

### 10.4 这一步解释了什么

> **错误率不是"$C$ 与 $h_\theta$ 谁大"的阶跃函数，而是信息变量的上尾概率。**

上尾概率随 $C$ **连续**变化。所以：

- **平滑崩塌不是理论的失败，是尾概率的必然形状。** §9.1 的观察 (ii) 得到解释。
- 过渡带的**宽度**由 $T$ 的**离散程度**决定——这就引出下一个新量。

### 10.5 操作方差熵 $\sigma_\theta$

> **定义 10.2（操作方差熵）。**
> $$\sigma_\theta^2\ :=\ \mathrm{Var}(T).$$

**(a) 直觉。** $h_\theta$ 说这个任务**平均**每步要多少比特；$\sigma_\theta$ 说这个需求**波动**多大。

**(b) 例子。** 两条地铁线，平均分叉率一样（$h_\theta$ 相同）：

- **A 线**：每一站都恰好有两个方向可选。需求稳定。$\sigma_\theta$ 小。
- **B 线**：大部分站是死板的一条道（几乎不用比特），但有三个巨型换乘枢纽（一次要好几比特）。平均一样，但**尖峰高**。$\sigma_\theta$ 大。

按 A 线的平均值去配带宽，在 B 线上会在枢纽处频繁失手。**$h_\theta$ 一样，但需要的容量不一样。**

**(d) 为什么这个量必须存在。** 因为没有它，理论只能回答"平均要多少"，回答不了"要多少才能有 99% 的把握"。而后者才是工程上唯一有用的问题形式。

> **TIC 此前用一个数刻画一个任务，现在用两个：$h_\theta$ 定位置，$\sigma_\theta$ 定宽度。**

### 10.6 推论 14.2（容错阈值）

由中心极限近似，
$$\varepsilon(C)\approx Q\!\Big(\frac{C-h_\theta}{\sigma_\theta}\Big),\qquad
\boxed{\ C^*(\varepsilon)\ \approx\ h_\theta+\sigma_\theta\,Q^{-1}(\varepsilon).\ }$$

**立刻读出两件事：**

1. **$\varepsilon>1/2$ 时 $Q^{-1}(\varepsilon)<0$，故 $C^*<h_\theta$。** §8 的判据是"成功率越过 0.5"，是一个**高容错**判据——阈值**必须**低于 $h_\theta$。§9.1 观察 (i) 的负号是理论预出来的，不是异常。
2. **旧陈述 $C\ge h_\theta$ 对应 $\varepsilon\to0$**，是零容错特例。

### 10.7 数值验证

- **界的有效性**：33 个 $(C,m)$ 组合，**违例 0/33**。
- **top-$M$ 最优性**：§8 实验实际使用的编码器，其实测错误率与 $\varepsilon_{\mathrm{opt}}$ 逐点吻合（最大偏差 0.0046）。**这排除了"编码器太笨"这一替代解释**——那个编码器就是一步最优码。
- **$\sigma_\theta$ 的实测值**：$m=2$ 为 0.5132，$m=3$ 为 0.4653，$m=6$ 为 0.7061；且与 $h_\theta$ 一样，**对状态数与物理熵率免疫**。

### 10.8 推论 14.4：只用任务结构预测阈值（闭环）

这是对定理14 最严格的检验：**不拟合任何参数**，只从任务定义推出阈值。

设任务要求连续 $L$ 步无误跟踪，每回合 $T$ 步（约 $T/L$ 次独立机会）。达到成功率 $\pi$ 所容忍的每步跟踪错误率为
$$\varepsilon_{\text{task}}=1-\Big[1-(1-\pi)^{L/T}\Big]^{1/L},$$
再由定理14(a) 反解 $C^*_{\text{pred}}=\varepsilon_{\mathrm{opt}}^{-1}(\varepsilon_{\text{task}})$。

代入 §8 实验的任务定义（$L=6,\ T=60,\ \pi=0.5$，**全部是任务定义，非拟合参数**）：$\varepsilon_{\text{task}}=0.3627$。

| | $h_\theta$ | $C^*$ 预测 | $C^*$ 实测 | 新误差 | 旧误差（$C^*=h_\theta$） |
|---|---|---|---|---|---|
| $m=2$, $K=1$, $N=6$ | 1.903 | 0.87 | 1.20 | −0.33 | +0.70 |
| $m=3$, $K=1$, $N=6$ | 3.099 | 2.21 | 1.96 | +0.25 | +1.14 |
| $m=2$, $K=4$ | 1.903 | 0.87 | 1.25 | −0.38 | +0.65 |
| $m=3$, $K=4$ | 3.099 | 2.21 | 1.95 | +0.26 | +1.15 |
| $m=2$, $N=12$ | 1.903 | 0.87 | 1.25 | −0.38 | +0.65 |
| $m=3$, $N=12$ | 3.099 | 2.21 | 2.32 | −0.11 | +0.78 |

$$\text{平均}|\text{误差}|:\ \mathbf{0.286}\ \text{比特}\quad\text{vs}\quad\text{旧预测 }0.846\ \text{比特}\qquad(\textbf{改善 }2.95\ \text{倍})$$

**更重要的是偏差的性质变了：** 旧预测偏差 $+0.846$，六点**同号**——系统性错误；新预测偏差 $-0.118$，误差有正有负——**残余噪声**。

### 10.9 推论 14.3：尖锐阈值是极限，不是现实

若允许 $n$ 步分块编码（智能体可以延迟 $n$ 步再承诺），相关量为 $T_n/n$，其标准差为 $\sigma_\theta/\sqrt n$（独立近似）。于是
$$C^*(\varepsilon)\approx h_\theta+\frac{\sigma_\theta}{\sqrt n}Q^{-1}(\varepsilon)\ \xrightarrow[n\to\infty]{}\ h_\theta.$$

**实测（$m=2$，$h_\theta=1.903$）：**

| $n$ | 1 | 2 | 4 | 6 | 8 | 11 |
|---|---|---|---|---|---|---|
| $C^*(0.5)$ | 0.437 | 1.105 | 1.473 | 1.595 | 1.650 | **1.708** |

**阈值单调爬向 $h_\theta$，过渡带同步收窄（1.362 → 0.367）。**

> **和解：旧的带宽定律在无限分组长度、零容错的极限上完全正确。它错在被当成了一般情形。** 智能体不能攒够一千步再决定往哪走，所以 TIC 需要的是**有限分组长度**版本。

**(b) 例子。** 你如果可以说"等我走十步再一次性告诉你我在哪"，那么平均下来你能压缩得很好，误差也小。但如果你**每一步都要根据对方的位置决定自己往哪走**，你就没有攒的余地。**能等待的智能体和必须即刻行动的智能体，面对的是不同的信息论。**

这也给了承诺关系一个定量后果：**延迟承诺的步数与信道宽度可以互换。**

### 10.10 三条诚实的负结果

我们如实报告定理14 未通过的部分。

**(1) $1/\sqrt n$ 这个速率不成立于可达的 $n$。** $W(n)\sqrt n$ 本应收敛到 $1.683\,\sigma_\theta=0.864$，实测到 $n=11$ 仍在 1.216 且继续下降；拟合指数 0.77–0.87，**收窄比预测更快**。

**诊断（我们先猜错了一次，记在这里）**：原以为精确曲线比信息尾 $\Pr[T_n/n>C]$ **更窄**（界有松弛）。**实测相反**——精确曲线更宽，比值 2.33→1.56。而**信息尾自身的宽度符合预测**（$n=6$：实测 0.3617 vs 理论 0.3526，差 2.6%）。

> **结论：$1/\sqrt n$ 律准确描述的是那条界，不是最优码误差曲线本身。** 推论 14.3 应改述为"**过渡宽度以 $1/\sqrt n$ 为渐近下包络**"，不能宣称等号。

**(2) 高斯形式在小商链上不准。** 在 4/9 块的商链上，$m=2$、$C=2$ 处精确值为 0.0000 而高斯给 0.4248——CLT 不适用。

**但这一条后来被翻案了**（§11.2）：在 16–36 块的商链上，高斯形式的误差降到 **0.3%**。所以正确的表述是**有效条件**，不是"高斯近似不准"。

**(3) 一档实验作废。** $m=6$ 的成功率在**所有** $C$ 上都封顶在约 0.10。诊断：$m=6$ 时区即单元格，要求连续 6 步精确同格，噪声下两智能体同时留在原地的概率约 $0.85^2=0.72$，六步约 $0.14$——**任务本身几乎不可完成，与带宽无关**。按难度混淆剔除，不进阈值统计。

> 这给出定律的一条边界：**带宽定律给协作定上界，不保证可达性。** 控制问题本身太难时，$C\ge h_\theta$ 不是充分条件。

## 11. $\sigma_\theta$ 是一个真正一般的量吗

§10 的全部 $\sigma_\theta$ 测量都来自同一族环境。在下结论前必须问：**它们是不是恰好落在一个退化的特例里？**

### 11.1 一个被发现的退化

在会合环面上，商核的**每一行都是同一个分布的置换**（$m=2$ 时每行皆为 $\{0.36,0.32,0.16,0.16\}$）。这有一个我们没有要求过的后果：**信息变量 $T$ 逐步 i.i.d.**，方差熵的全部自协方差项恒为零。实测 $\mathrm{sd}(T_n/n)=\sigma_\theta/\sqrt n$ **精确成立**（所有 $n$ 比值 1.0000）。

看着像完美验证，其实是**环境对称性造成的**。一般马氏链没有这个性质。

### 11.2 破除对称性后的重测

我们因此构造了一个**各行形状真正不同**的环境（地形随区变化的定向风 + 拖拽），得到 10/16 与 21/36 种不同行形状。

**造这个环境时踩的坑，本身有理论内容。** 最显而易见的做法——让动作实现噪声 $p$ 随区变化——**完全不起作用**：16 行仍只有 1 种形状。原因是在均匀参考策略下按意图动作平均，每个移动的概率是
$$\tfrac15(1-p)+\tfrac45\cdot\tfrac{p}{4}=\tfrac15,$$
**与 $p$ 无关，地形精确抵消。**

> **规则：任何对智能体自身动作集的重新加权，在均匀参考策略下都会被平均掉；只有与动作无关的环境侧随机性才能改变操作链。**
>
> 换句话说：**操作链对"智能体的动作噪声怎么分布"免疫，只对环境的不确定性敏感。**

**结果一：自协方差项（首次测到）**

| $n$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| $\mathrm{sd}(T_n/n)\big/(\sigma_\theta/\sqrt n)$ | 1.0000 | 1.0108 | 1.0183 | **1.0235** |

信息序列**正自相关**，修正项非零。但量级只有百分之几：**i.i.d. 近似可以放心用作近似，不能当恒等式。**

**结果二：宽度 $\propto\sigma_\theta$——推论 14.2 通过**

在 16–36 块商链上，用拖拽把 $\sigma_\theta$ 拉开 1.51 倍：

| $m$ | drag | 块数 | $h_\theta$ | $\sigma_\theta$ | $W_{20\text{–}80}$ | $W/\sigma_\theta$ |
|---|---|---|---|---|---|---|
| 4 | 0.00 | 16 | 3.211 | 1.229 | 2.008 | 1.634 |
| 4 | 0.30 | 16 | 2.707 | 1.612 | 2.726 | 1.691 |
| 4 | 0.60 | 16 | 1.916 | 1.909 | 3.180 | 1.665 |
| 6 | 0.15 | 36 | 2.989 | 1.424 | 2.459 | 1.727 |
| 6 | 0.55 | 36 | 2.084 | 1.856 | 3.105 | 1.674 |

$$W/\sigma_\theta=1.678\pm0.033\ (\text{相对离散 }2.0\%),\qquad\text{高斯预测 }1.683$$

**误差 0.3%。** §10.10(2) 的负结果是小商链假象，已翻案。

**结果三：有效域边界（实测出来的）**

drag$=0.8$ 时（$\sigma_\theta=1.894>h_\theta=1.187$，分布极度偏斜）：$W/\sigma_\theta=\mathbf{0.049}$，**彻底失效**。

> **推论 14.2 的有效条件：$\sigma_\theta\lesssim h_\theta$。** 越过它 $T$ 不再近似正态，宽度公式失去意义。

# 第四部分　时间维度：本体漂移

## 12. 当"什么算数"本身在变

### 12.1 问题

前面所有结果都假设**抽象是固定的**：目标不变，动力学不变，于是 $\sim_\theta^*$ 不变。开放世界里这不成立。世界会改变你的本体本身——今天要紧的区分，明天可能不要紧了。

一个自然的猜想（本理论的早期版本把它当定理）：

> **两级速率条件（原版）。** 记本体过程的熵率为 $h_A$，则
> $$C\ \ge\ h_\theta+h_A.$$
> 直觉：你既要跟上世界的状态，又要跟上"世界的规则"的变化，两笔账相加。

**这条被实测证伪了。** 而且错的方向很有意思：**它多收了钱。**

### 12.2 两种漂移，必须分开

**(b) 例子——这是本节的关键，请慢读。**

你和朋友每天要会合一次。

**情形甲（可吸收）**：会合点每天都换——今天在东门，明天在北广场，后天在地铁口。**但规则始终是"在对方位置的正东 100 米处"。**

问：会合点变得这么频繁，你们需要多传信息吗？

**不需要。** 你只要知道**对方在哪**，就能算出今天该去哪。会合点"漂移"得再快，你要传的东西没变——**因为漂移被你们的坐标系吸收了。**

**情形乙（不可吸收）**：今天约的是**吃饭**，明天变成**打球**，后天变成**看电影**。

问：这需要多传信息吗？

**需要。** 因为"该带什么、该穿什么、该几点到"全都变了。**这不是位置变了，是"什么算数"变了。** 你必须被告知。

> **同样叫"本体漂移"，甲的代价是零，乙的代价是满额。**

### 12.3 实测

**实验 7a（可吸收）。** 会合环面，加一个漂移的会合目标 $g\in\mathbb Z_m$：目标是"$x$ 偏移等于 $g$"而不是"等于 0"。

**精化算法给出的商是 $((dx-g)\bmod m,\ dy\bmod m)$——$g$ 被整个吸收了。**

理由是结构性的：$g'-g$ 的分布与 $g$ 无关，而 $dx$ 的增量只依赖动作与噪声，所以 $(dx-g)$ 自身封闭。**一个跟踪"自己相对于当前目标的偏移"的智能体，根本不需要知道目标在哪。**

| $p$ | $h_A$ | $h_\theta$ | $C^*(0.5)$ |
|---|---|---|---|
| 0.00 | 0.0000 | 3.0987 | 1.792 |
| 0.10 | 0.5690 | 3.1085 | 1.800 |
| 0.30 | **1.1813** | 3.1235 | **1.816** |

$h_A$ 从 0 拉到 **1.18 比特/步**，$C^*$ 只动了 **0.024 比特**。斜率 **0.021**，不是 1。

**实验 7b（不可吸收）。** 漂移变量决定**任务是关于哪个坐标的**：$g=0$ 时目标是 $x$ 对齐，$g=1$ 时目标是 $y$ 对齐。没有任何状态平移能吸收它——$g$ 改变的是任务的**身份**，不是它的**位置**。

| $p$ | $h_A$ | $h_\theta$ | $h_\theta-h_A$ | $\sigma_\theta$ | $C^*(0.5)$ |
|---|---|---|---|---|---|
| 0.05 | 0.2864 | 3.3851 | **3.0987** | 1.036 | 1.883 |
| 0.10 | 0.4690 | 3.5677 | **3.0987** | 1.059 | 1.985 |
| 0.20 | 0.7219 | 3.8206 | **3.0987** | 0.926 | 2.174 |
| 0.30 | 0.8813 | 3.9800 | **3.0987** | 0.728 | 2.427 |
| 0.45 | 0.9928 | 4.0915 | **3.0987** | 0.487 | 2.733 |

两件事同时成立：

1. **加性分解是精确的。** $h_\theta-h_A$ 在整个扫描上恒为 3.0987，且这个数**正是 $m=3$ 无漂移时的 $h_\theta$**。即 $\mathrm{d}h_\theta/\mathrm{d}h_A=\mathbf{1.0000}$，逐位成立。
2. **阈值斜率 $\mathrm{d}C^*/\mathrm{d}h_A=1.131$。**

斜率略高于 1 不是噪声，是**定理14 的已知效应**：$C^*(\varepsilon)\approx h_\theta+\sigma_\theta Q^{-1}(\varepsilon)$，而 $\sigma_\theta$ 在扫描中从 1.036 降到 0.487。**速率需求本身的斜率是精确的 1，阈值斜率带上了 $\sigma_\theta$ 变化的二阶项。**

> **这是本文中两条独立导出的定理第一次在数据上互相咬合。**

### 12.4 定理11′

> **定理11′（两级速率条件，修正版）。** 设本体过程的熵率为 $h_A$。将其分解为可被典范抽象吸收的部分与不可吸收的部分，记后者的速率为 $h_A^{\perp}$。则
> $$\boxed{\ C^*(\varepsilon)\ \approx\ h_\theta+h_A^{\perp}+\sigma_\theta\,Q^{-1}(\varepsilon).\ }$$
> 当本体漂移是状态空间的一个对称性时 $h_A^\perp=0$，漂移不花带宽；当漂移改变哪些区分算数时 $h_A^\perp=h_A$，一比特换一比特。

> **判据（可计算，不需要判断力）。** 把本体变量并入状态后跑一次精化。**商块数不增加 ⇒ 漂移可吸收；增加多少，$h_A^\perp$ 就有多少。**

### 12.5 为什么这与主张一致

回到 §1.2 那句话：**在目标所决定的最粗抽象上选择迁移。**

"最粗"这个词在这里做了实际工作：**最粗的抽象会自动把一切可吸收的漂移一并抹掉。** 定理11′ 不是一条补丁，它是主张在时间维度上的展开。

**并且它给一个流行的担忧划了界：**

> **世界变化快，不等于代价高。只有"改变了什么算重要"的变化才收费。**
>
> 位置在动、结构不动的世界，可以任意快地动。

# 第五部分　连续极限

## 13. 表格会死吗

### 13.1 风险陈述

到此为止所有定理都假设**有限状态、可枚举划分、已知或可估的转移核**。现实是连续、高维的。前车之鉴就在隔壁：bisimulation metric 数学上很漂亮，规模化一直吃力。

**如果抽象机器过不了函数逼近这一关，以上全部只是一个玩具形式化。** 我们把这一条列为本理论最可能的死因，并正面测试它。

### 13.2 一个先决问题：$h_\theta$ 在连续空间里不存在

**微分熵依赖坐标系、可以为负。** "比特/步"这个说法在连续状态上没有意义。

正确的替代是**率失真量**：

> **定义 13.1。** 把操作变量跟踪到均方失真 $D$ 以内所需的速率
> $$R_\theta(D)=\tfrac12\log_2\frac{\sigma_e^2}{D}\quad\text{比特/步}.$$

**这有一个重要后果，值得单列：**

> **零误差的带宽定律在连续空间里根本无法陈述**——任何连续变量的零失真跟踪都要求**无限**速率。
>
> **所以定理14 的容错参数 $\varepsilon$ 不是给被证伪的常数打的补丁，它是理论能进入连续世界的前提条件。**

**(b) 例子。** 停车入位。你需要知道车位边线的位置——但精确到毫米？纳米？**要求零误差，需要无限的信息。** 你实际需要的是"精确到能停进去"，那是一个**失真容限**，而它决定了你需要多少比特。**没有容限，问题无解；有了容限，问题有一个有限的答案。**

### 13.3 实验设计

连续环面 $[0,1)^d$ 上两个智能体，任务为会合：环上距离 $|e|<\delta$ 且保持 $L$ 步，其中 $e=(x_1-x_2)\bmod1$ 是**一维**操作变量，无论物理状态有多少维。任务无关坐标把物理维数抬到 $d=4/10/20$，且这些坐标**都带独立噪声**——它们真的要花速率去跟踪，只是不进目标。

- **无枚举**：状态是实向量，不存在有限状态集。
- **划分精化不是慢，是无定义。**
- **抽象必须从采样轨迹中学**，用随机傅里叶特征 + 岭回归，全程不告诉学习器任务依赖 $x_1-x_2$、不告诉它哪些坐标无关。
- 因为 $e$ 在圆上，它是原坐标的**非线性**函数，任何线性映射都取不到它。

三个编码器，**同一速率**，只差量化什么：

| | 量化什么 | 译码 |
|---|---|---|
| **phys** | 原始物理状态向量 | **解析精确公式**——故意给基线最强的译码器 |
| **learned** | 学到的任务抽象 $\psi(s)$ | **学到的**读出——所有逼近误差算在待检验假设的**不利**方向 |
| **opvar** | 真实操作变量 $e$ | 直接 |

### 13.4 第二个被失败逼出来的理论点

**第一次尝试彻底失败。** 定理4 的连续版本，直觉上应该是"多步目标预测"：
$$\psi(s)=\big(\mathbb E[\text{goal}_{t+h}\mid s]\big)_{h=1..H}.$$
实测读出误差 **0.194**，约等于瞎猜。

原因是原理性的：目标 $|e|<\delta$ **对偏移符号对称**，随机策略下动力学也对称，于是 $+e$ 与 $-e$ 的目标预测剖面完全相同，特征把它们合并了。

**但控制器必须区分 $+e$ 与 $-e$**——它们要求相反的移动。

**解答早在定义 4.1 里，是我们在翻译时丢掉的：条件 (D) 是逐动作量化的。** 对动作取平均恰好抹掉那个量词。正确的连续特征必须**逐动作条件化**：
$$\psi(s)=\big(\mathbb E[\text{goal}_{t+h}\mid s,\,a_t=a]\big)_{a\in A,\;h=1..H}.$$

改正后误差从 **0.194 → 0.0055**。

> **命题 13.1：目标预测充分性 ≠ 控制充分性，差别正是逐动作量词。** 在连续与有限情形同样成立。
>
> **这对后继表示（successor representation）文献是一个直接的提醒**：常用的动作平均版本在对称任务上会遇到同一个问题。

**(b) 例子。** 你闭着眼睛，别人告诉你"你离目标 3 米"。这个信息对"你还有多远"完全充分，但对"该往哪走"**完全无用**——因为左 3 米和右 3 米听起来一样。**你需要的不是"离目标多远"，而是"如果我往左走会怎样、往右走会怎样"。那就是逐动作条件化。**

### 13.5 结果

| $n_{\text{irr}}$ | 物理维数 $d$ | $R_\theta$ | $R_{\text{phys}}$ | phys 最佳 | learned 最佳 | opvar 最佳 |
|---|---|---|---|---|---|---|
| 0 | 4 | **1.24** | 2.95 | 0.42 | 0.80 | 0.95 |
| 3 | 10 | **1.24** | 7.37 | 0.17 | 0.76 | 0.97 |
| 8 | 20 | **1.24** | 14.74 | 0.20 | 0.52 | **0.97** |

信道消融：九个格点全部 $\le0.03$。

**三件事：**

**(1) 速率需求由任务变量决定，与物理维数无关——带宽定律的连续形式存活。**
opvar 行在 $d=4\to20$ 上是**平的**（0.95/0.97/0.97），阈值都在 $C\approx3$，而同期 $R_{\text{phys}}$ 从 2.95 涨到 **14.74**（5 倍）。这是 §8 双向解离的连续版本，而且更强。

**(2) 量化物理状态随维数崩塌，即便给它精确译码器。** 0.42 → 0.17 → 0.20。

**(3) 学到的抽象随维数退化，但那是样本复杂度，不是墙。** 0.80 → 0.76 → 0.52。控制实验（$d=20$，只增加轨迹数）：

| 样本量 | 18,000 | 50,000 |
|---|---|---|
| 读出误差 | 0.0736 | **0.0474** |

样本量 2.8 倍换来误差降 36%，**持续改善、没有平台**。退化落在**可学性**上，不落在**可表示性**上。

### 13.6 判决：不是整体死，是精确分裂

| 主张 | 连续极限下 |
|---|---|
| **速率类**（$h_\theta\Rightarrow R_\theta$、带宽定律、容错阈值） | **完整存活** |
| **可学性** | **付维数代价，但是样本复杂度，不是墙** |

### 13.7 残留的暴露面（本节最重要的保留意见）

逼近器用了**低阶交互先验**（随机频率最多 2 个非零分量，等价于二次核）。**没有这个先验，$d=10$ 时学习就已经失败**（误差 0.199，与瞎猜相当）。

先验本身是正当的：它没有告诉学习器**哪一对**坐标要紧（$\binom d2$ 对一视同仁），只说答案是低阶交互——这是所有多项式核/高斯核方法的通常假设。

**但结论必须条件化：**

> TIC 的抽象机器在连续高维下存活，**前提是任务结构与逼近器的归纳偏置相匹配**。真实高维任务未必有低阶结构。

**"表格死"因此从"最可能的死因"降级为"当结构与偏置不匹配时死"。** 后者是所有机器学习共有的问题，不是 TIC 特有的——这个区别很重要，**但不能当作已经解决**。

# 第六部分　其余结果、边界与定位

## 14. 其余定理（简述）

为完整起见，列出支撑性结果。它们的证明在附录 A，此处只给陈述与一句直觉。

> **定理7（抽象可学）。** $\sim_\theta^*$ 可由样本估计的 $\varepsilon$-精化学出，有夹逼界与样本复杂度。**过分裂安全，过合并致命**——多切一刀只是浪费带宽，少切一刀会把必须区分的状态混在一起。
>
> *例子*：把"红灯"和"绿灯"分开是安全的冗余；把它们合并是事故。

> **定理8（同一性降低他人的跟踪成本）。** 一个实体对自己施加的约束（保持某些慢变量不变），降低了**别人**跟踪它所需的比特数。
>
> *例子*：一个作息规律的人更容易被预测，因此"描述他此刻在做什么"需要的信息更少。守信本身是一种带宽补贴。

> **定理9（最小任务充分记忆 = 操作状态）。** 为完成任务所需保留的最小历史信息，恰好是当前的 $\sim_\theta^*$-块。
>
> *这一条与计算力学的因果态（Shalizi–Crutchfield）等价，我们把它作为地基引用，不作为发明。*

> **定理10（多任务 = 公共细化）。** 同时服务多个任务，所需的抽象是各任务抽象的**公共细化**，带宽相应上升。
>
> *例子*：一张同时要支持"换乘"和"步行距离"的地图，必须比只支持换乘的地铁图更细，因此更贵。

> **定理12（目标源自生存力）。** 在给定世界结构下，目标可由生存流形导出；工具性目标与好奇心（当 $h_A>0$ 时）随之导出。**此条为条件性结果**：依赖世界具有相应结构，我们的负结果表明它不普遍成立。

> **定理13（可生存同一性构成格）。** 可生存的同一性 = 受控不变集；它们对并封闭，故存在**唯一极大元**（生存核）。
>
> **反直觉的单调性**：容忍度越紧，最小可生存同一性越**宽**。*例子*：只跑一个片区的骑手，撞上该片区的偶发大堵车就完蛋；要把违规率压得更低，他必须**同时**会跑三个片区，才能在一处出事时改跑别处。**越怕出错，越需要多手准备，而不是越专一。**
>
> **那为什么现实里专家都很专注？** 因为更宽的同一性横跨更多行为种类 → 抽象类更多 → $h_\theta$ 更高 → 需要更多容量。**特化是容量经济，不是最优化。**

### 14.1 理论边界的正式声明

自由参数的收缩链：一堆概念 →（定理4）目标 →（定理12）同一性 →（定理13）**生存格中的某个元素** → **止于此**。

> **TIC 决定可能同一性的格，不决定实体实际占据其中哪一个。**
>
> 理由不是"难"，是**类型不对**：那由历史、路径依赖、偶然性决定，不是计算事实。**物理学给出可能的轨道，不给出哪颗行星在哪条上。**

要移动这条边界，需要一套关于实体**形成**（种群/变异/选择）的理论。我们不建议在本框架内追求它。

## 17. 认识论状态：这套东西被检验到什么程度

**我们认为这一节比任何结果都重要。**

### 17.1 已经过的检验

- **数学检验**：14 条定理互不矛盾，经过一次系统的一致性审计（六处矛盾已解决并记录）。
- **受控检验**：7 个实验。核心主张（协作代价由任务抽象定价）在**三次相互独立的解离**中未破。
- **自我否证**：形式系统**否决过作者三次**（定理5 推翻中心命题；精化算法两次纠正作者的手算预测），实验**推翻过理论三次**（尖锐阈值、两级速率、$m=6$ 档）。
- **外部检验**：核心主张在一个我们没有设计的标准公开环境上被确认（§17.2）。

> **一个被做局的实验，不会推翻自己的理论。** 这些否证是"设置未被操纵"的证据，也是我们能提供的最强的内部保证。

### 17.2 一个外部环境上的确认

**核心主张已在一个我们没有设计的标准公开环境上得到确认。**

环境为 **PettingZoo / mpe2 `simple_spread_v3`**（Lowe et al., NeurIPS 2017）——多智能体强化学习的标准 benchmark，物理、奖励、观测布局与动作语义全部由包固定，我们一处未改。

该任务的协作内容是一次**地标指派**，因此

| | 变量 | 大小 |
|---|---|---|
| 物理变量 | 发送方的观测块 | 10 个连续维 |
| 任务变量 | 地标指派 | $\log_2 3=\mathbf{1.58}$ 比特 |

**这个比值不是我们挑的，是 `simple_spread` 的奖励结构决定的。**

| $C$（比特/步） | 1.58 | 3.00 | 4.00 | 6.00 |
|---|---|---|---|---|
| **oracle**（任务变量） | $\mathbf{-44.75}$ | $-44.75$ | $-44.75$ | $-44.75$ |
| **learned**（学到的抽象） | $-46.28$ | $-48.21$ | $-46.95$ | $-46.69$ |
| **phys**（物理状态，解析译码） | $-69.22$ | $-63.51$ | $-59.49$ | $\mathbf{-51.54}$ |

无信道上界为 $-44.75$。三条读数：

1. **任务变量恰好值 $\log_23=1.58$ 比特并在此饱和**——oracle 在 $C=1.58$ 处即达上界，之后再给比特毫无收益。**这个数不是拟合的。**
2. **学到的抽象几乎同样便宜**：$C=1.58$ 处 $-46.28$，与上界差约一个标准误。抽象是学出来的，不是给的（保留集上指派准确率 0.901，随机 0.333）。
3. **编码物理状态贵 4 倍以上且不收敛**：$C=6.00$ 比特时仍未追上 learned 在 $1.58$ 比特处的成绩。

**信道消融**（§8.5）：oracle 落差 17.22、learned 14.20，三者消融后都收敛到约 $-61$ 的无信息基线。phys 落差仅 2.30——**它本来就没在传多少任务信息**，与读数 3 互相印证。

> **这一节的意义不在于又赢了一次，而在于赢在别人的场地上：** `simple_spread` 的结构是 Lowe 等人在 2017 年出于完全不同的目的写下的，理论对它作了正确的定量预测。

### 17.3 仍然没有经过的检验

**必须同样说清楚：**

- **仍是仿真，不是真实系统。**
- **仍是我们自己跑的，不是第三方复现。**
- 外部环境上只检验了**核心主张**（类编码 vs 状态编码）。$\sigma_\theta$、容错阈值 $C^*(\varepsilon)$、漂移吸收性 $h_A^\perp$ **均未在外部环境上检验**。
- 学到的抽象使用了"预测他人指派"这一监督信号；**完全无监督地发现该抽象没有测。**

### 17.4 一处已发现的实现缺陷（及影响核查）

我们在自己的精化算法中发现一处数值缺陷并已修正，如实报告：

签名相等性原用 `np.round(sig, 9)`。**定点舍入不是合法的相等性测试**——数学上相同但沿不同浮点路径算出的值可能跨在舍入边界两侧，在**任何**精度下都被判为不等。

症状：某环境的块数随舍入常数在 9 与 27 之间乱跳（ROUND=9 → 27,27,**9**,27；ROUND=6 → 9,9,**27**,27）。**纯浮点噪声冒充结构，方向是欠合并，导致 $h_\theta$ 被高估。**

修正为按绝对容差聚类。**影响核查：§8 与 §10 的全部数字逐条重算，完全未变；三级 sanity check 仍全部通过。**

> **方法学结论：定点舍入判等在划分精化中是不安全的。**
>
> **认识论结论：我们在自己代码里找到过一个 bug，这意味着可能还有别的。** 已核查的部分未受影响，但这不构成"其余都对"的保证。

### 17.5 一句总结

> **TIC 经受住了数学检验、受控检验，以及一次在他人环境上的检验；它还没有经受住——因为还没有接受——真实世界与第三方复现的检验。**

## 18. 未解决问题

按我们判断的价值排序：

1. **把 $\sigma_\theta$、容错阈值与漂移吸收性也搬到外部环境上。** 核心主张已在 MPE 上确认（§17.2），但定理14 与定理11′ 的量在外部环境上**一次都没测过**——那是现在最大的不对称。
2. **真实系统与第三方复现。** 这是唯一能改变 §17.3 的事。**不要去和 LLM 比 benchmark：TIC 不预测困惑度，那是死路。**
3. **部分可吸收的漂移**（$0<h_A^\perp<h_A$）。定理11′ 恰恰在那里最有内容，而我们只测了两个端点。
4. **按任务失真分配速率。** §13 发现：量化"正确的变量"还不够，还要按任务的失真需求**分配**速率（均匀量化操作变量会浪费——实测在低 $C$ 处反而不如学到的抽象）。率失真理论有现成工具，TIC 还没接上。
5. **推论 14.3 的正确渐近形式。** 现有陈述只能作为下包络。
6. **$\sigma_\theta$ 在强相关链上的行为。** 自协方差修正只在 $n\le4$、弱相关下测过。
7. **定理2 下界的可达性。** 目前只有经验证据表明朴素编码能逼近到 0.3–0.9 比特以内，没有解析的可达性构造。

## 附录 B　实验规格与反坑清单

我们建议任何复现此类实验的人逐条检查以下七条。前六条来自常规审慎，**第七条来自一次真实事故**。

| # | 检查项 | 为什么 |
|---|---|---|
| 1 | 每个智能体的随机性必须**独立** | 曾出现两智能体共用划分顺序，导致"协作率 100%"，实为同步犯同一个错 |
| 2 | 精化算法必须先在**手算小例**上验证 | 曾用错函数变体，在无目标信号时平凡退化，结果看起来"验证"了理论 |
| 3 | 成功率必须**跨越 0 和 1** | 恒 0 或恒 1 的格点没有信息量；$m=6$ 档因此作废 |
| 4 | $h$ 与 $h_\theta$ 必须用**同一估计器** | 否则不等式可能因估计误差而假性成立/失败 |
| 5 | 规模轴必须**真的改变要改变的量** | 曾用"状态数 ×3.16"作规模轴，$h$ 只动 0.07 比特，等于空转 |
| 6 | 保存**原始数据**（均值、方差、种子数） | 只看均值会漏掉分布问题 |
| **7** | **信道消融对照** | **把所有传输符号随机化后重跑；若成绩不塌，决策没走信道，该批数据作废** |

**第七条的来历**：一个早期实现的策略表按真实联合状态索引，信道形同虚设，$C=1$ 比特时成功率已是 1.000。六条常规检查全部"通过"，**只有消融对照能抓住它**。
